# YOLO AutoInstaller 断点恢复功能用户操作指南

## 一、功能简介

YOLO AutoInstaller 2.0 新增了**断点恢复**功能。如果您在下载模型或部署环境时不小心关闭了程序，或者电脑意外重启，再次打开软件时可以从中断的地方继续，无需重新开始。

---

## 二、启动时的恢复提示

### 2.1 什么情况下会出现恢复提示？

当您上次使用软件进行"一键部署"时，如果部署没有完成就关闭了程序，再次打开软件时会自动弹出恢复对话框。

### 2.2 恢复对话框说明

对话框会显示以下信息：

| 显示内容 | 含义 |
|----------|------|
| YOLO 版本 | 上次部署的是哪个 YOLO 版本（如 YOLOv8） |
| Conda 环境名 | 上次创建的环境名称 |
| 开始时间 | 上次部署开始的时间 |
| 当前步骤 | 中断时正在执行到哪一步 |
| 已完成步骤 | 已经成功完成的步骤列表 |
| 下载进度 | 如果有文件下载到一半，会显示已下载的百分比 |

如果有文件损坏，还会以黄色区域提示：**"检测到 X 个文件损坏，继续部署时将自动重新下载"**。

### 2.3 三个选项怎么选？

#### ▶ 继续部署（推荐）

- **作用**：自动跳过上已经完成的步骤，从中断的地方继续部署
- **适用场景**：您想完成上次的部署，不想重新开始
- **效果**：已下载的文件会保留，下载到一半的文件会继续下载，已安装的环境不会重复安装

#### 🗑 放弃并清理

- **作用**：删除上次下载到一半的文件和配置缓存，重新开始
- **适用场景**：您想换一个新的 YOLO 版本部署，或者上次部署出了问题想彻底重来
- **注意**：此操作会删除已下载的模型文件，但**不会删除已创建的 Conda 环境**（避免误删）

#### 暂不处理，下次启动再问我

- **作用**：关闭对话框，不做任何操作
- **适用场景**：您现在不想处理，想先看看其他功能
- **效果**：下次打开软件时还会再次提示

## 三、部署过程中的新功能

### 3.1 更详细的进度显示

部署过程中的下载进度现在会显示：

```
yolov8n.pt: 45.3% (47.5/104.9 MB, 2.3 MB/s, 预计剩余 00:25)
```

| 显示内容 | 含义 |
|----------|------|
| 百分比 | 当前下载进度 |
| 已下载/总大小 | 已下载多少 MB / 文件总大小多少 MB |
| 下载速度 | 当前网速（MB/秒） |
| 预计剩余 | 按当前速度估算的剩余时间 |

### 3.2 关闭按钮的保护

当部署、环境安装或训练正在进行时，点击窗口右上角的 **×** 关闭按钮，不会再直接退出，而是弹出选择对话框。

#### 选项一：🔽 最小化到后台继续

- **作用**：窗口隐藏到系统托盘（右下角小图标），部署继续在后台进行
- **查看进度**：双击托盘图标可以重新打开窗口
- **完成提醒**：部署完成后窗口会自动弹出显示结果
- **托盘菜单**：右键托盘图标可以选择"打开主窗口"或"退出"

#### 选项二：💾 关闭并保留进度

- **作用**：直接关闭程序，但部署进度已经自动保存
- **恢复方式**：下次打开软件时会提示"是否继续上次未完成的部署"
- **适用场景**：您需要关闭电脑，下次再继续

> **注意**：如果当前正在进行**模型训练**，此选项会显示为 **"⛔ 直接关闭（终止训练）"**，因为训练中断后无法恢复，只能重新开始训练。

#### 选项三：取消

- **作用**：不关闭程序，返回主窗口继续部署

## 四、常见问题

### Q1：恢复部署时提示"Conda 未就绪"怎么办？

**原因**：恢复部署需要检测到 Conda 才能继续。

**解决**：
1. 如果您之前已经安装过 Conda，请确保它已正确添加到系统 PATH
2. 或者先点击"一键部署"页面的"系统检测"，让程序自动扫描 Conda
3. 如果 Conda 被卸载了，需要重新安装 Conda 后再恢复

### Q2：恢复时提示"文件损坏，将重新下载"是什么意思？

**原因**：程序会对已下载的文件进行安全校验（SHA256），如果文件在关机过程中损坏，会自动标记重新下载。

**解决**：这是正常保护机制，点击"继续部署"即可，程序会自动重新下载损坏的文件。

### Q3：选择"放弃并清理"会删除什么？

**会删除**：
- 下载到一半的 `.part` 临时文件
- 已下载完成的模型文件（.pt）
- 部署状态记录文件

**不会删除**：
- 已创建的 Conda 虚拟环境（避免您误删后需要重装）
- 已克隆的 YOLO 源码目录

### Q4：部署到一半断网了怎么办？

**解决**：
1. 如果程序还在运行，重新联网后会自动继续下载（断点续传）
2. 如果程序已关闭，下次打开时选择"继续部署"，下载会从中断处继续

### Q5：如何彻底删除所有残留？

如果您想完全清理：
1. 在恢复对话框选择"放弃并清理"（删除下载文件）
2. 在"一键部署"页面，选择对应环境，点击"删除环境"（删除 Conda 环境）
3. 手动删除工作目录下的源码文件夹（如 `C:\yolo_workspace\yolov8`）

## 五、使用建议

| 场景 | 建议操作 |
|------|----------|
| 部署到一半需要关机 | 点击关闭 → 选择"💾 关闭并保留进度" |
| 想边部署边做其他事 | 点击关闭 → 选择"🔽 最小化到后台继续" |
| 网络不稳定经常断 | 放心部署，断网后重新联网会自动续传 |
| 想换 YOLO 版本重新部署 | 选择"🗑 放弃并清理"，然后重新选择版本 |
| 部署失败想排查问题 | 查看程序根目录下的日志文件（`.log`） |
